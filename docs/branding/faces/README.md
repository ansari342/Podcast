# Host face references

Reference photos for animating the hosts in the 5-second intro. See
[`../intro-credits-proposal.json`](../intro-credits-proposal.json) for the
shot list, style and timing.

Stills from the Episode 1 camera recordings. Two per host: `-1` is a relaxed,
front-facing reference and `-2` is a big smile. Use the smile for the intro's
pop-up and bonk frames.

| Host  | Files                        | Notable features                                   | Prop in the intro          | Pops up on beat |
|-------|------------------------------|----------------------------------------------------|----------------------------|-----------------|
| Ahsan | `ahsan-1.jpg`, `ahsan-2.jpg` | Backwards denim cap, short beard, gray hoodie      | Glowing laptop or phone    | 2               |
| Ahmad | `ahmad-1.jpg`, `ahmad-2.jpg` | Shaved head, round clear glasses, full beard, headset, gray hoodie | Airhorn         | 3               |
| Omar  | `omar-1.jpg`, `omar-2.jpg`   | Very short hair, thick eyebrows, full dark beard, white zip top | Fork with pancake | 4               |

## Notes for whoever animates them

- Style: flat 2D cartoon heads, thick black outlines, no gradients or 3D.
  Exaggerate one feature per person (Ahsan's cap, Ahmad's glasses,
  Omar's eyebrows).
- Treat Ahmad's headset as recording gear and leave it off the cartoon.
- Palette: black, white, red `#E63946` and yellow `#FFD166` (bonk stars only).
- Export each head as its own layer (SVG or PNG with transparency), facing
  the camera, plus a blink and a cross-eyed frame for the final bonk.
